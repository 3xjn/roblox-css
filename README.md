# roblox-css

CSS cascade, values, layout, text, and native rendering for Roblox.

## Repository setup

This repository contains the `@3xjn/roblox-css` package. It is in active development and has not been published to npm.

Related packages:

- [@3xjn/roblox-unicode](https://github.com/3xjn/roblox-unicode)

Authenticate Git with GitHub before running `npm install`; development dependencies use the related private GitHub repositories.

Build the Luau module with `rojo build default.project.json --output Css.rbxm`. Runtime imports expect the related modules as siblings in the Roblox package tree.

The development gallery and cross-package tests remain in the private [roblox-styling workspace](https://github.com/3xjn/roblox-styling).
